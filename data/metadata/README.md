# Class metadata

`class_host_mapping_s14.csv` contains the Table S14 class-to-host mappings for 89 PlantWild and 115 PlantSeg classes, including the merged-host sensitivity mapping and health status.

`labels_final.csv` contains the 59 disease-class symptom and pathogen annotations. `plantwild_class_groups.csv` contains all 89 classes, including the 30 healthy classes listed in `plantwild_healthy_classes.csv`.

`plantdoc_classes.csv` retains the 28 raw PlantDoc directory classes in model class-ID order, with their saved host and health mappings. These raw directory labels are not merged.
